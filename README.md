## 01 · Air

**I turn drone flights into maps people can act on.** This is the newest part of the map and the one growing fastest.

It runs under my own brand, **MapMyAcre**: land surveys for people who own land. A flight goes up over an estate. What comes down is a measured boundary, a stitched aerial map, contours, and a 3D model of the land that opens in a browser.

| From one flight | What it is |
| :--- | :--- |
| **Boundary** | The plot outline, measured in hectares, in the formats surveyors and compliance teams already use. |
| **Aerial map** | Hundreds of photos stitched into one image accurate enough to measure on. |
| **3D model** | The estate as terrain you can orbit, zoom and share as a link. |
| **Run planner** | Which estates are mapped, which are flown, and which are left to fly. |

Lately that has meant coffee estates in the Western Ghats, where a clean boundary is what deforestation-free export rules ask for.

## 05 · Rack

**I host my own things.** A small fleet of servers, a Raspberry Pi and the machines at home, on one private network. Client sites, databases, backups and team tools all run there.

It is mostly private, and mostly boring on purpose: one security baseline on every server, a health check every morning, backups that get pulled and tested.
